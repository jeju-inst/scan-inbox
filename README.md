# Scan Inbox

Windows·macOS에서 스캔 폴더를 **미처리 문서함**으로 유지하기 위한 로컬 우선 앱 구상입니다.

> 현재 단계: **계획·OSS 조사만 완료. 실행 가능한 앱이나 설치 프로그램은 아직 없습니다.** 기존 OSS를 먼저 시험하고, 요구사항 격차가 확인될 때만 개발합니다.

## 원하는 경험

1. 최초 설정에서 스캔 폴더, 처리완료 폴더, 선택적인 관련 문서 폴더를 지정합니다.
2. `지금 처리` 또는 예약·감시로 새 PDF를 발견합니다.
3. 문서 제목으로 이름을 제안하고, 필요한 페이지에 검색 가능한 OCR 텍스트층을 추가합니다.
4. 제안된 이름·OCR 상태·이동 위치를 검토하고 승인합니다.
5. 성공한 문서만 처리완료 폴더 또는 승인된 관련 폴더로 옮깁니다. 실패·검토 대기는 스캔 폴더에 남습니다.

기본은 외부 전송 없음, 미리보기 우선, 원본 보존, 덮어쓰기 금지입니다. 자동 분류 이동은 첫 버전의 기본값이 아닙니다.

## 공개 범위

범용 코드·설계·합성 테스트만 공개합니다. 실제 문서, 원래 파일명, 사내 폴더 구조, 실호스트 경로, OCR 본문, 인증 정보는 커밋하지 않습니다. 공개 코드의 라이선스와 회사 문서의 클라우드 AI 전송 허용은 별도 문제입니다. 본 저장소의 독자 작성물은 [MIT](LICENSE)이며, 외부 프로젝트·모델·재배포 바이너리에는 각각의 라이선스가 적용됩니다.
